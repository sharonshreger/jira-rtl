# Jira RTL — local source build

This repository contains a local build of the open-source **Jira RTL Extension** by or321, with its original MIT license preserved.

Upstream: https://github.com/or321/Jira-RTL

## Build

```bash
npm install
npm run build
```

Then in Microsoft Edge open `edge://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the generated `dist` folder.

## Why this repository exists

This copy is intended for environments where installing the extension from the Edge Add-ons store is unavailable, while local unpacked extensions are permitted.
